# Style Guide - Book Worm

- **Vibe:** A Netflix-inspired Book collection. Sleek and immersive.
- **Mobile-First:** Optimize for 390px wide devices; it should still look intentional on desktop. Use full width when displaying Books
- **Colors:** near-black background, off-white text, vibrant blue for call to action buttons (sign-in, edit log, reading status), vibrant green for create buttons (sign-up, write log, add to library) crimson red for delete buttons (delete log, remove from library)
- **Type:** bold, high-impact sans-serif, like a movie or streaming platform
- **Cards:** standard aspect ratio (3:4) with placeholder frame for missing covers
- **Touch Targets:** Minimum 44px x 44px for interactive elements; modals, buttons and detail fields should be full-width on Mobile
- **Motion:** fast and purposeful, elements slide smoothly on scrolling or dragging, subtle toast or toggle appropriately when performing actions, always respect prefers-reduced-motion
- **Navigation:** Top navigation Bar, / = (Home • Book Worm • Sign-In or Display Name); /details/:id = (Home • Book Details • Sign-In or Display Name)
- **Accessibility:** visible keyboard focus, labels on every input, contrast AA or better
